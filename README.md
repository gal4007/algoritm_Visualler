# 📊 Визуализатор алгоритмов

Интерактивное веб-приложение для изучения и визуализации алгоритмов сортировки и поиска. Позволяет наглядно наблюдать за выполнением алгоритмов, разбирать каждый шаг и изучать соответствующий код на C++.

## ✨ Возможности

- 📈 Визуализация алгоритмов сортировки и поиска.
- ⏯️ Автоматическое и пошаговое выполнение алгоритмов.
- 🎨 Цветовая индикация текущих операций и состояний элементов.
- 💻 Отображение кода на C++ с подсветкой текущей строки.
- ⚡ Настройка скорости выполнения.
- 🎲 Генерация случайных массивов.
- 🔊 Звуковое сопровождение с возможностью отключения.
- 📊 Подсчёт сравнений, обменов и других операций.
- 🌙 Современный интерфейс с тёмной темой.
- ⌨️ Управление с помощью горячих клавиш.

## 🧮 Реализованные алгоритмы

### Сортировка
- Bubble Sort — сортировка пузырьком.
- Selection Sort — сортировка выбором.
- Insertion Sort — сортировка вставками.
- Shell Sort — сортировка Шелла.
- Quick Sort — быстрая сортировка.

### Поиск
- Linear Search — линейный поиск.
- Binary Search — бинарный поиск.
- Jump Search — прыжковый поиск.
- Interpolation Search — интерполяционный поиск.

## 🚀 Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/ВАШ-НИК/НАЗВАНИЕ-РЕПОЗИТОРИЯ.git
```

### 2. Переход в папку проекта

```bash
cd НАЗВАНИЕ-РЕПОЗИТОРИЯ
```

### 3. Установка зависимостей

```bash
npm install
```

### 4. Запуск проекта

```bash
npm run dev
```

После запуска открой адрес, указанный в терминале. По умолчанию проект использует порт 3000.

## ⌨️ Горячие клавиши

| Клавиша | Действие |
|---|---|
| Space | Старт / Пауза |
| → | Следующий шаг |
| M | Включить / выключить звук |
| R | Сброс |
| N | Новый массив |
